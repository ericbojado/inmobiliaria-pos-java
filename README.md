# Sistema de Gestión Inmobiliaria POS

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)
![Status](https://img.shields.io/badge/Status-En%20Desarrollo-green?style=for-the-badge)

Este es el proyecto final de programación en Java. El sistema consiste en una aplicación de escritorio diseñada para la administración de inventario, ventas y clientes de una inmobiliaria.

## Funciones
El sistema incluye:
* **Captura de Propiedades:** Registro detallado de inmuebles (terrenos, casas, etc.).
* **Inventario:** Control y visualización de propiedades disponibles.
* **Venta de Propiedades:** Módulo de transacciones.
* **Registro de Ventas:** Registro detallado de las ventas.
* **Catálogo de Clientes:** Administración de compradores.
* **Catálogo de Usuarios:** Gestión de accesos al sistema.

---

## Características del Programa
El programa cuenta con:
1.  **Validación Completa:** Entradas de datos protegidas contra errores.
2.  **Base de Datos Inicial:** 30 registros precargados para demostración.
3.  **Interfaz Gráfica:** Manejo de formularios y listas.

## Instalación y Ejecución
1.  **Clonar el repositorio:** _git clone [https://github.com/ericbojado/inmobiliaria-pos-java.git](https://github.com/ericbojado/inmobiliaria-pos-java.git)_
2.  **Importar** el proyecto en tu IDE (NetBeans, IntelliJ o Eclipse).
3.  **Asegurarse de tener instalado** JDK 17 o superior.
4.  **Ejecutar** la clase Main.java.
